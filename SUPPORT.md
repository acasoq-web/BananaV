# Getting help

Thanks for using BananaV! Where to go depends on what you need:

| You want to… | Go to |
|---|---|
| Ask a question, get help with a project, share what you made | The community chat on **[Discord](https://discord.gg/vtC7Yasz98)** |
| Read news and guides | **[BananaV's website](https://bananav-editor.github.io/)** |
| Report a bug | A **Bug report** in the [issues](https://github.com/acasoq-web/BananaV/issues/new/choose) |
| Suggest a feature | A **Feature request** in the [issues](https://github.com/acasoq-web/BananaV/issues/new/choose) |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) says (never in a public issue) |
| Contribute code, translations or tests | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Support the project | The **Support the project** section of the [README](README.md#support-the-project) |

## Before asking

- Check that you have the latest release
  ([Releases](https://github.com/acasoq-web/BananaV/releases)).
- Search the [issues](https://github.com/acasoq-web/BananaV/issues): your
  question may have an answer already.
- Say which BananaV version and system (Windows or Linux, x64 or ARM64) you
  use, and what you did, expected and got.

The issue tracker is for bugs and feature requests: questions there are
answered on Discord instead.

Answers come from the people who make BananaV and from other users, in their
own time. Please be patient and kind: everyone here follows the
[Code of Conduct](CODE_OF_CONDUCT.md).

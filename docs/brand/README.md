# BananaV's brand files

The logo — a banana and the bar of a V — in the versions the README, the
website and articles about BananaV use. The application's own copies are in
[`packaging/icons`](../../packaging/icons) (the source); these are kept
identical to them.

| File | Use it for |
|---|---|
| `bananav-icon.svg` | The application icon: the logo on a dark rounded square. Works on any background. |
| `bananav-logo.svg` | The logo on its dark square, square corners. |
| `bananav-logo-transparent.svg` | The logo alone. Only on dark backgrounds: its yellow fades on white. |
| `bananav.png` | The icon at 256 × 256 pixels, for places that take no SVG. |
| `social-preview.png` | GitHub's social preview (1280 × 640), drawn from `social-preview.svg`. |

Colors:

| | Hex |
|---|---|
| Banana yellow | `#FDD825` |
| Banana shade | `#DA9E08` |
| Stem brown | `#6B3E12` |
| Background | `#27282D` |

Please use the files as they are: don't change their colors or proportions,
add effects, or combine the logo with other marks. The name "BananaV" and the
logo identify the official project; what you may and may not do with them is
in [TRADEMARKS.md](../../TRADEMARKS.md) (a draft). Every file here has an
`.attribution` sidecar, listed in [ATTRIBUTION.md](../../ATTRIBUTION.md).
